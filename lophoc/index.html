    Chưa chọn học sinh

    Chọn một học sinh ở danh sách bên trái để xem lý lịch hoặc ghi nhận xét. Nếu đây là năm học mới, hãy nhập danh sách từ file Excel trước.

    Xuất phiếu nhận xét (Word)
    Chọn một hoặc nhiều tháng để xuất — mỗi tháng là một phiếu riêng trong cùng file Word.

    Nhập danh sách từ Excel

    Tải lên file danh sách học sinh (.xls, .xlsx, .csv). Bạn có thể kiểm tra lại trước khi lưu.
    Chọn file Excel từ máy tính, hoặc kéo thả vào đây.
